# 890 ARQ — Sitio Web Corporativo (v2.0)

Repositorio oficial de la segunda versión (v2.0) del portal corporativo y portafolio de proyectos de 890 ARQ; oficina de arquitectura, construcción y gestión normativa municipal en la Región de Valparaíso, Chile.

Este proyecto corresponde a una reconstrucción integral desde cero de la plataforma web original (www.890arq.cl). La primera versión (v1.0) operaba sobre un CMS monolítico tradicional apoyado en WordPress y PHP, dependiendo en gran medida del constructor visual Elementor y de una colección de plugins de terceros para resolver componentes de interfaz, menús y formularios. Para superar las limitaciones de rendimiento, seguridad y mantenibilidad de dicho stack heredado, esta nueva iteración abandona esa infraestructura en favor de una arquitectura moderna orientada al rendimiento, tipado estático estricto y gestión de contenidos en la nube.

## Stack Tecnológico

* **Framework Web:** Next.js (App Router, Server Components & Server Actions)
* **Librería de Interfaz:** React 19
* **Lenguaje:** TypeScript (modo estricto)
* **Estilos y Maquetación:** Tailwind CSS v4 + Lucide React
* **Base de Datos y Almacenamiento Multimedia:** Supabase (PostgreSQL + Supabase Storage)
* **Validación de Esquemas:** Zod
* **Servicio de Correo Transaccional:** Resend
* **Infraestructura y Despliegue:** Vercel
